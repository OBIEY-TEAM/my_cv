# NOM DU PROJET : "Luka Mosala SaaS" - Générateur Automatisé de Candidatures Sur Mesure
# DESTINATAIRE IA : Jules AI / Agent IA Autonome de Développement

---

## 1. VISION DU PROJET & OBJECTIF GÉNÉRAL
Construire la plateforme SaaS complète **Luka Mosala** (Mobile Flutter + Web React Client + Dashboard Admin Angular + Backend Django REST Framework) connectée aux API d'Intelligence Artificielle (Jules / OpenAI / Claude) et aux passerelles de paiement Mobile Money (Airtel Money, MTN Mobile Money, PayDunya).

L'application permet à tout utilisateur d'importer une offre d'emploi (via un lien URL, un fichier PDF ou un texte brut), une photo de profil et son profil/CV de référence (style README/markdown), puis de générer instantanément un dossier de candidature complet et sur mesure :
1. **CV Professionnel sur mesure (PDF - Strictement 1 page)** avec photo recadrée professionnellement.
2. **Lettre de Motivation personnalisée (PDF - Strictement 1 page)** structurée et rédigée selon l'offre.
3. **Email de candidature rédigé (.txt)** prêt à copier-coller.
4. **PDF de l'offre d'emploi originale** archivée.
5. **Arborescence de dossiers organisée** par site/organisme et intitulé de poste.

## 2. ARCHITECTURE TECHNIQUE GLOBALE DU SYSTÈME

```
 [ APPLICATION MOBILE FLUTTER WEB ]    [ WEB CLIENT REACT ]    [ DASHBOARD ADMIN ANGULAR ]
 (mobile-luka-mosala.onrender.com)   (client-luka-mosala.onrender.com) (admin-luka-mosala.onrender.com)
                 │                             │                              │
                 └─────────────────────────────┼──────────────────────────────┘
                                               │ (APIs REST / JSON / JWT)
                                               ▼
                           [ BACKEND DJANGO REST FRAMEWORK / PYTHON ]
                             (backend-luka-mosala.onrender.com)
                                 │             │               │
                 ┌───────────────┘             │               └───────────────┐
                 ▼                             ▼                               ▼
   [ BASE POSTGRESQL / REDIS ]   [ AGENT IA / JULES API ]   [ PAYMENTS FINTECH ]
    (Données Users, Subscriptions) (Génération CV/LM/Email)   (Airtel Money, MTN MoMo)
```

### A. Backend : Django REST Framework (DRF) + Python
- **API RESTful sécurisée :** Authentification JWT (SimpleJWT), CORS, throttled endpoints.
- **ORM & Base de données :** SQLite / PostgreSQL, Redis pour le caching.
- **Tâches Asynchrones & Queues :** Celery / Redis pour le scraping des offres web et la génération de PDF lourds sans bloquer l'API.
- **Intégration GitHub / Jules AI API :**
  * Service de synchronisation avec GitHub via Octokit / Git Python API.
  * Webhooks & appels API vers l'agent IA (Jules API / LLM) pour analyser l'offre et générer le contenu du CV, de la Lettre de Motivation et de l'Email.
- **Génération de PDF :** Moteur Python ReportLab / WeasyPrint pour générer des PDFs au design moderne respectant strictement la limite d'1 page.
- **Paiements Mobile Money :** Module d'intégration Webhook / REST avec les API Fintech (Airtel Money Congo, MTN Mobile Money Congo, PayDunya, SankMoney).

### B. Application Mobile : Flutter / Flutter Web
- **Multiplateforme :** iOS, Android et Flutter Web (déployé sur Render).
- **Gestion d'État :** BLoC / Provider / Riverpod.
- **Fonctionnalités Clés :**
  * Appareil photo intégré (Camera Plugin / Image Picker) pour capturer la photo de profil en direct ou choisir depuis la galerie.
  * Module de recadrage intelligent de photo de profil (Crop 1:1 buste/visage avec espace au-dessus de la tête).
  * Upload de fichiers (PDF d'offres d'emploi, Markdown README de profil).
  * Lecteur PDF natif pour prévisualiser le CV et la Lettre de Motivation générés.
  * Téléchargement & Partage direct (Share Plus, File Saver).

### C. Application Web Client : React.js / Vite / TypeScript
- **UI/UX Moderne :** Tailwind CSS, Shadcn/UI, Lucide Icons, Framer Motion.
- **Dashboard Réactif :**
  * Glisser-déposer (Drag & Drop) pour les fichiers d'offres et photos.
  * Éditeur Markdown / WYSIWYG pour éditer son profil README et ses compétences.
  * Prévisualisation en direct (Live PDF Preview) du CV et de la Lettre de Motivation.
  * Historique des candidatures et statut des paiements.

### D. Web Admin & Dashboard Organisateur : Angular 17+
- **Gestion Administrative :**
  * Supervision des utilisateurs, gestion des abonnements, validation des transactions Mobile Money.
  * Monitoring de la consommation des API IA et statistiques de génération de CV/Lettres.

### B. Gestion des Erreurs Courantes & Auto-Correction
En cas de page blanche, d'erreur serveur, ou d'erreur spécifique du type :
> `Blocked request. This host ("luka-mosala-web.onrender.com") is not allowed. To allow this host, add "luka-mosala-web.onrender.com" to preview.allowedHosts in vite.config.js.`

L'agent IA doit exécuter la procédure d'auto-correction suivante :
1. **Ouvrir et corriger la configuration Vite (`site_client_react/vite.config.js` ou `vite.config.ts`) :**
   ```javascript
   export default defineConfig({
     preview: {
       allowedHosts: ['luka-mosala-web.onrender.com', 'client-luka-mosala.onrender.com', '.onrender.com', 'all']
     },
     server: {
       allowedHosts: ['luka-mosala-web.onrender.com', 'client-luka-mosala.onrender.com', '.onrender.com', 'all']
     }
   })
   ```
2. **Corriger la configuration CORS / ALLOWED_HOSTS du backend Django (`settings.py`) :**
   ```python
   ALLOWED_HOSTS = ['backend-luka-mosala.onrender.com', 'luka-mosala-web.onrender.com', '.onrender.com', 'localhost']
   CORS_ALLOWED_ORIGINS = [
       "https://client-luka-mosala.onrender.com",
       "https://luka-mosala-web.onrender.com",
       "https://admin-luka-mosala.onrender.com",
       "https://mobile-luka-mosala.onrender.com"
   ]
   ```
3. **Commit et Push immédiat** sur la branche de déploiement (`jules-8374694265899943435-377d46a8`).
4. **Revisiter le site** `https://luka-mosala-web.onrender.com` dès que le déploiement est vert sur Render, prendre une nouvelle capture d'écran et valider le bon fonctionnement jusqu'à l'obtention d'un résultat visuel 100% fonctionnel et conforme.
