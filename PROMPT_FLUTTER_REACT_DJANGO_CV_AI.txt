# PROMPT SPÉCIFICATION ARCHITECTURALE & DÉVELOPPEMENT D'APPLICATION
# NOM DU PROJET : "Luka Mosala SaaS" - Générateur Automatisé de Candidatures Sur Mesure
# DESTINATAIRE IA : Jules AI / Agent IA Autonome de Développement

---

## 1. VISION DU PROJET & OBJECTIF GÉNÉRAL
Construire la plateforme SaaS complète **Luka Mosala** (Mobile Flutter + Web React Client + Dashboard Admin Angular + Backend Django REST Framework) connectée aux API d'Intelligence Artificielle (Jules / OpenAI / Claude) et aux passerelles de paiement Mobile Money (Airtel Money, MTN Mobile Money, PayDunya).

L'application permet à tout utilisateur d'importer une offre d'emploi (via un lien URL, un fichier PDF ou un texte brut), une photo de profil et son profil/CV de référence (style README/markdown), puis de générer instantanément un dossier de candidature complet et sur mesure :
1. **CV Professionnel sur mesure (PDF - Strictement 1 page)** avec photo recadrée professionnellement.
2. **Lettre de Motivation personnalisée (PDF - Strictement 1 page)** structurée et rédigée selon l'offre.
3. **Email de candidature rédigé (.txt)** prêt à copier-coller.
4. **PDF de l'offre d'emploi originale** archivée.
5. **Arborescence de dossiers organisée** par site/organisme et intitulé de poste.

## 2. ARCHITECTURE TECHNIQUE GLOBALE DU SYSTÈME

```
 [ APPLICATION MOBILE FLUTTER WEB ]    [ WEB CLIENT REACT ]    [ DASHBOARD ADMIN ANGULAR ]
 (mobile-luka-mosala.onrender.com)   (client-luka-mosala.onrender.com) (admin-luka-mosala.onrender.com)
                 │                             │                              │
                 └─────────────────────────────┼──────────────────────────────┘
                                               │ (APIs REST / JSON / JWT)
                                               ▼
                           [ BACKEND DJANGO REST FRAMEWORK / PYTHON ]
                             (backend-luka-mosala.onrender.com)
                                 │             │               │
                 ┌───────────────┘             │               └───────────────┐
                 ▼                             ▼                               ▼
   [ BASE POSTGRESQL / REDIS ]   [ AGENT IA / JULES API ]   [ PAYMENTS FINTECH ]
    (Données Users, Subscriptions) (Génération CV/LM/Email)   (Airtel Money, MTN MoMo)
```

### A. Backend : Django REST Framework (DRF) + Python
- **API RESTful sécurisée :** Authentification JWT (SimpleJWT), CORS, throttled endpoints.
- **ORM & Base de données :** SQLite / PostgreSQL, Redis pour le caching.
- **Tâches Asynchrones & Queues :** Celery / Redis pour le scraping des offres web et la génération de PDF lourds sans bloquer l'API.
- **Intégration GitHub / Jules AI API :**
  * Service de synchronisation avec GitHub via Octokit / Git Python API.
  * Webhooks & appels API vers l'agent IA (Jules API / LLM) pour analyser l'offre et générer le contenu du CV, de la Lettre de Motivation et de l'Email.
- **Génération de PDF :** Moteur Python ReportLab / WeasyPrint pour générer des PDFs au design moderne respectant strictement la limite d'1 page.
- **Paiements Mobile Money :** Module d'intégration Webhook / REST avec les API Fintech (Airtel Money Congo, MTN Mobile Money Congo, PayDunya, SankMoney).

### B. Application Mobile : Flutter / Flutter Web
- **Multiplateforme :** iOS, Android et Flutter Web (déployé sur Render).
- **Gestion d'État :** BLoC / Provider / Riverpod.
- **Fonctionnalités Clés :**
  * Appareil photo intégré (Camera Plugin / Image Picker) pour capturer la photo de profil en direct ou choisir depuis la galerie.
  * Module de recadrage intelligent de photo de profil (Crop 1:1 buste/visage avec espace au-dessus de la tête).
  * Upload de fichiers (PDF d'offres d'emploi, Markdown README de profil).
  * Lecteur PDF natif pour prévisualiser le CV et la Lettre de Motivation générés.
  * Téléchargement & Partage direct (Share Plus, File Saver).

### C. Application Web Client : React.js / Vite / TypeScript
- **UI/UX Moderne :** Tailwind CSS, Shadcn/UI, Lucide Icons, Framer Motion.
- **Dashboard Réactif :**
  * Glisser-déposer (Drag & Drop) pour les fichiers d'offres et photos.
  * Éditeur Markdown / WYSIWYG pour éditer son profil README et ses compétences.
  * Prévisualisation en direct (Live PDF Preview) du CV et de la Lettre de Motivation.
  * Historique des candidatures et statut des paiements.

### D. Web Admin & Dashboard Organisateur : Angular 17+
- **Gestion Administrative :**
  * Supervision des utilisateurs, gestion des abonnements, validation des transactions Mobile Money.
  * Monitoring de la consommation des API IA et statistiques de génération de CV/Lettres.

## 3. CONFIGURATION RENDER BLUEPRINT (`render.yaml`)

Demande à l'IA de générer le fichier `render.yaml` à la racine du projet pour permettre le déploiement gratuit et automatisé de l'ensemble des 4 services sur Render :

```yaml
services:
  # 1. Backend API Service (Django REST Framework / Python)
  - type: web
    name: backend-luka-mosala
    env: python
    plan: free
    region: frankfurt
    buildCommand: "pip install -r backend/requirements.txt && python backend/manage.py migrate"
    startCommand: "cd backend && PYTHONPATH=. gunicorn luka_mosala.wsgi:application --bind 0.0.0.0:$PORT"
    envVars:
      - key: PYTHON_VERSION
        value: 3.12.13
      - key: USE_SQLITE
        value: "True"
      - key: DJANGO_SETTINGS_MODULE
        value: luka_mosala.settings
      - key: CORS_ALLOWED_ORIGINS
        value: "https://client-luka-mosala.onrender.com,https://admin-luka-mosala.onrender.com,https://mobile-luka-mosala.onrender.com"

  # 2. Web Client Service (React.js / Vite)
  - type: web
    name: client-luka-mosala
    env: node
    plan: free
    region: frankfurt
    buildCommand: "cd site_client_react && npm install --include=dev && npx vite build"
    startCommand: "cd site_client_react && npx vite preview --host 0.0.0.0 --port $PORT"
    envVars:
      - key: VITE_API_BASE_URL
        value: "https://backend-luka-mosala.onrender.com/api"

  # 3. Web Admin & Dashboard Service (Angular 17+)
  - type: web
    name: admin-luka-mosala
    env: node
    plan: free
    region: frankfurt
    buildCommand: "cd site_admin_angular && npm install --include=dev && npm run build"
    startCommand: "npx serve -s site_admin_angular/dist/site_admin_angular/browser -p $PORT"
    envVars:
      - key: VITE_API_BASE_URL
        value: "https://backend-luka-mosala.onrender.com/api"

  # 4. Mobile Web App Service (Flutter Web)
  - type: web
    name: mobile-luka-mosala
    env: node
    plan: free
    region: frankfurt
    buildCommand: "git clone https://github.com/flutter/flutter.git -b stable --depth 1 && export PATH=\"$PATH:`pwd`/flutter/bin\" && cd site_client_mobile && flutter create . --platforms web && flutter build web --release"
    startCommand: "npx serve -s site_client_mobile/build/web -p $PORT"
    envVars:
      - key: VITE_API_BASE_URL
        value: "https://backend-luka-mosala.onrender.com/api"
```

## 4. FONCTIONNALITÉS COMPLÈTES À DÉVELOPPER (SPÉCIFICATIONS DÉTAILLÉES)

### 1. Gestion de Compte & Authentification Utilisateur
- **Inscription & Connexion :** Email/Mot de passe, OAuth2 (Google, GitHub).
- **Gestion du Profil :** Nom, Prénom, Titre principal, Numéro de téléphone (+242...), Email, Villes (Pointe-Noire, Brazzaville...), Liens sociaux (LinkedIn, GitHub).
- **Gestion du Profil de Référence (README) :** Saisie des compétences, formations, expériences et projets sous forme structurée README/Markdown.
- **Gestion de la Photo de Profil :** Prise de photo intégrée (caméra) ou upload. Module de recadrage automatique professionnel (visage centré, espace au-dessus de la tête conservé).

### 2. Formules d'Abonnement & Paiement Fintech
- **Plans / Formules d'abonnement :**
  * *Formule Découverte (Gratuit) :* 1 candidature offerte.
  * *Formule Pack 5 Candidatures :* 2 000 FCFA.
  * *Formule Illimitée Mensuelle :* 5 000 FCFA / mois.
- **Modes de Paiement Intégrés :**
  * **Airtel Money** (Initiation USSD Push + vérification automatique du statut).
  * **MTN Mobile Money (MoMo)** (API MoMo Pay Push USSD).
  * **PayDunya / Card Payment**.
- **Historique & Facturation :**
  * Reçus de paiement téléchargeables en PDF.
  * Suivi du solde de crédits de candidatures et statut de l'abonnement.

### 3. Module d'Analyse d'Offre & Génération IA (Jules AI Engine)
- **Sources d'Offre Acceptées :**
  1. Lien URL (Scraping automatique de sites comme ACPE, BlueCollarCongo, Emploi Congo, etc.).
  2. Document PDF d'offre téléversé.
  3. Copier-coller de texte brut d'offre.
- **Moteur de Génération IA :**
  * Analyse sémantique des exigences de l'offre (compétences clés, hard skills, soft skills, missions).
  * Reformulation et sur-mesure dynamique du profil utilisateur (issu du README).
- **Livrables Générés Automatiquement :**
  * `OBIEY-[ABRÉVIATION-POSTE]-CV.pdf` : CV moderne 2 colonnes avec photo, **exactement 1 page**.
  * `OBIEY-[ABRÉVIATION-POSTE]-LM.pdf` : Lettre de motivation ciblée, **exactement 1 page**.
  * `OBIEY-[ABRÉVIATION-POSTE]-EMAIL.txt` : Email prêt à l'envoi avec objet et corps structuré.
  * `OBIEY-[ABRÉVIATION-POSTE]-OFFRE.pdf` : Archivage PDF de l'offre nettoyée.
- **Arborescence Répertoire Téléchargeable :**
  * Dossier ZIP téléchargeable contenant l'arborescence complète organisée (ex: `/acpe/Développeur Full Stack Mobile/...`).
